---

## 1. Objet

`1.0.0-rc.1` constitue la première base immuable réellement publiée pour l’exercice D-017.

Cette candidate n’est pas une release stable et ne doit pas être présentée comme `v1.0.0`.

Elle sert à :

```text
figer une référence Core identifiable
→ dériver un dépôt pilote conservant l’historique Git
→ enregistrer la provenance dans core-origin.json
→ développer un petit module métier
→ produire ensuite une évolution Core compatible
→ valider un upgrade réel du pilote
```

---

## 10. Limites connues

`1.0.0-rc.1` reste une release candidate de validation de distribution.

Elle ne signifie pas qu’un SaaS dérivé est automatiquement prêt pour la production. Les sujets dépendant du produit réel restent notamment :

- Billing / Payment ;
- conformité juridique/RGPD finale ;
- observabilité ;
- stockage Files de production ;
- sauvegarde/restauration ;
- déploiement, reverse proxy et infrastructure ;
- E2E métier du produit dérivé.

---

## 11. Condition de promotion stable

La promotion vers `1.0.0` stable reste interdite tant que D-017 n’a pas démontré :

```text

+ évolution Core post-dérivation
+ upgrade réel du pilote
+ tests Core/métier/E2E verts
+ analyse des conflits
+ aucun blocker Core 1.0 restant
```
