## Correctif WorkspaceFilesPage

Avant ce patch, le montage de `WorkspaceFilesPage` avec une recherche vide programmait malgré tout un timer de debounce.

Si l’utilisateur changeait de page avant l’expiration des 300 ms, ce timer pouvait ensuite exécuter `setPage(1)` et annuler la navigation serveur.

Le comportement devient :

```text
searchInput normalisé === search actif
→ aucun timer
→ aucune réinitialisation différée de pagination
```

Lorsqu’une recherche change réellement :

```text
nouvelle recherche
→ debounce conservé
→ application de la recherche
→ retour page 1
```

La source de données reste RTK Query et la pagination reste serveur.

## Stabilité des tests Select

Base UI positionne ses popups à partir de la géométrie du trigger. Sous jsdom, un élément peut retourner une géométrie nulle, ce qui peut refermer le popup avant l’interrogation de ses options.

Les tests concernés utilisent désormais :

```text
géométrie déterministe du trigger
+
findByRole pour attendre le montage asynchrone de l’option
```

Aucune modification n’est apportée à la primitive `Select` de production.
